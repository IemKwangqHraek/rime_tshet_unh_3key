# 三拼鍵位評價框架

本框架比較鍵位分配：聲母基幹 → 韻身 → 韻尾及聲調的輸入順序固定，片段可任意配鍵，**不計記憶、助記、學習或改鍵成本**。目標是比較熟練輸入時的操作負擔。本文是完整評價規格；已完成單鍵、二鍵及三鍵動作的探索性實作，範圍見[實現計劃](鍵位搜尋實現計劃.md)及[鍵位優化結果](鍵位優化結果.md)，尚無全局最優或實際提速的結論。

## 1. 比較範圍與硬條件

固定全拼、分段、字音資料及候選詞典，只改 [JSON 鍵位](../config/keyboards/default.json)。每個音節三鍵，空片段也佔一鍵；同一槽位內，同一片段始終對應同一個 a–z 按鍵。所有已驗證的 3,808 個地位及補充「怎」均須有碼且不同音節無碰撞，不因低頻而豁免。

[build_rime.mjs](../scripts/build_rime.mjs) 的 `syllables()` 與 `encodeLayout()` 已提供音節全集及鍵表驗證，可直接復用。此條件僅涵蓋既有資料，新增讀音後須重驗。

分兩個搜尋層次：

1. **固定共鍵組，重排物理鍵位。** 各槽位分別對現有共鍵組作一對一配鍵，可使用 26 鍵中的任意位置。這種重排保持完整編碼的可區分性，適合作爲首輪。
2. **允許重組共鍵。** 可以拆分或合併組、移動個別片段；每個方案必須重新檢查完整三鍵碰撞。現行 24／23／21 的用鍵數不是優化目標，也不要求維持。

固定三鍵且音節無碰撞時，同音字的候選歧義不會因單純改鍵而消失。因此基本碼長和同音字重碼率不是這一輪的排名指標。若實際使用補全、簡碼、選字、空格上屏等操作，另行回放其完整按鍵流。

## 2. 語料與頻率

分別建立古文、現代書面語、現代口語三組測試集；古文再按時代與文體分層。使用中古音輸入先秦文獻或現代文章時，文本年代決定「輸入甚麼」，讀音仍依本方案的中古音規則。

| 資料來源 | 可用資訊 | 在本框架中的用途與限制 |
| --- | --- | --- |
| [中研院語言教學資源區](https://elearning.ling.sinica.edu.tw/cwordfreq_index.html) | 索引列出現代、近代、上古漢語及唐詩、宋詞詞頻 | 古今詞頻的候選來源；本次查到搜尋索引，但直接讀取頁面回傳 502，尚未確認下載檔格式與可用性 |
| [中研院古漢語文獻語料庫](https://ancientchinese.ling.sinica.edu.tw/ASACC_index/) | 文獻檢索、版本及使用說明 | 選取與核對分時代文獻；不能將有檢索頁等同於已有可批量下載資料 |
| [中國哲學書電子化計劃 Text Tools](https://ctext.org/plugins/texttools/) | 字符 n-gram、段落及標點邊界選項，支援匯入文本 | 古文字頻及相鄰字頻；按實際可取得文本和使用條件建立資料集，字符二元組不冒充已斷詞的詞頻 |
| [SUBTLEX-CH 官方下載頁](https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexch) | 字頻、詞頻及詞性頻率檔 | 現代日常語言的對照組；源於影視字幕，不能代表所有書面文體，也不提供本方案的中古讀音標註 |

SUBTLEX-CH 的原始研究使用約 4,680 萬字的影視字幕，詳見 [Cai 與 Brysbaert（2010）](https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexch/cai.pdf)。以上網頁於 2026-09-28 查詢；正式匯入時記錄實際下載地址、版本、許可、SHA-256、清洗及字形轉換規則。

各來源先按本身有效字數正規化，再依用途混合，不能直接拼接原始次數，否則最大語料會主宰結果。沒有個人使用比例時，先分榜，不假定一個通用的古今比例。古文大類內也需明定是按實際字數、按作品等權，還是按文體配重。

保留虛詞；它們的高頻正是按鍵負擔的一部分。移除標記、編者說明和重複版本。繁簡、異體轉換保留來源與歧義，不把「发→發／髮」等一對多映射直接全算給每個字。不跨標點、缺字或未識別片段拼接出虛假的相鄰字。

## 3. 從字頻到音節頻率

字頻不等於音節頻率。首版依使用者選定的簡化，**同一字的不同中古讀音等概率分配，各次出現的讀音選擇暫視爲獨立**，不要求斷詞、語境消歧或人工標音。這是估計模型，並非宣稱實際讀音等頻。

設 R(c) 爲字符 c 在本方案中去重後的全拼集合，字頻次數爲 C(c)。每個讀音獲得 C(c)/|R(c)| 次；再將所有字符對同一音節的貢獻相加，除以有效字符總數 N，得到 p(s)。同一字各讀音的概率和必須爲 1。

《廣韻》的重複條目若推導出同一全拼，只算一個讀音；推導時使用字頭以保留特殊字規則。記錄讀音表版本，所有候選鍵表共用同一分配。以後若已有可靠讀音資料，可替換概率表；首版不把人工校訂或其他讀音假設的敏感度測試作爲完成前提。

不能把一個字的全部頻率加給每個《廣韻》讀音，也不能拿普通話拼音直接替代中古讀音。碼表 [positions.tsv](../data/positions.tsv) 每地位一行，其均勻分佈只適合結構性基準，不代表實際文本。

每組語料報告：按出現次數計的字音覆蓋率、字種覆蓋率、未識別字清單及頻率、多音字佔有效字次的比例。缺失資料不作零成本輸入；不同鍵表使用同一有效樣本。相鄰音節頻率從實際字對及上述等概率分配生成，不能默認 p(s,t)=p(s)p(t)。讀音選擇獨立不意味着相鄰字符獨立。

### 相鄰字對的統計與分配

對每份文本以一字爲步長滑動長度二的窗口，統計有方向的 C(x,y)。例如「學而時習之，不亦說乎」產生「學而、而時、時習、習之」及「不亦、亦說、說乎」，不產生「之不」。字對不必構成詞，因此可直接涵蓋詞內及詞間銜接，古文也不必先斷詞。

以 Unicode 碼點遍歷，避免拆開擴展區漢字。標點、段落、文件邊界及未識別字符都終止窗口；不能先刪除再把兩端接上。來源因排版造成的字間空白、軟換行，只有在清洗規則可確認時才移除；其他空白預設斷開。統計有效字數 N、有效相鄰字對數 B，並另報字對覆蓋率。

若字對 (x,y) 出現 C(x,y) 次，x 有 m 個讀音、y 有 n 個讀音，則每個音節組合 (s,t) 分配 C(x,y)/(mn) 次。例如某字對出現 120 次，兩字分別有 2、3 個讀音，六種音節對各得 20 次，總量仍是 120。即使 x=y，首版亦按兩次出現獨立選讀音處理。

```text
W(s,t) = Σₓ,ᵧ C(x,y) · 1[s∈R(x)] · 1[t∈R(y)] / (|R(x)| |R(y)|)
相鄰音節對的概率 = W(s,t) / B
每字成本公式使用的邊界頻率 p(s,t) = W(s,t) / N
```

前者用於描述字對組成，後者用於與字內成本合算；兩個分母不可混用。對有效樣本，所有 W(s,t) 的總和必須等於 B。字頻和詞頻表本身無法還原完整 C(x,y)，所以首版最好直接取原文，同時生成字頻與字對頻率。

計算時只需掃描原文一次，保存稀疏字對計數，不必枚舉整篇文章的讀音組合，也不必隨機抽一個讀音。等概率期望可以直接精確累加。

### 搜尋鍵位時的預計算

對二鍵銜接成本，可進一步把 W(s,t) 聚合成「前音節第三段片段 → 後音節第一段片段」的頻率矩陣 M(r,i)。片段取自既有三段表，不以當前物理按鍵爲索引，因此鍵位改排甚至重組共鍵時都可復用。

```text
跨字成本(L) = Σᵣ,ᵢ M(r,i) · v(L.k3[r], L.k1[i]) / N
```

字內第一→第二段、第二→第三段也各自預計算片段對矩陣，換鍵表時只重新查鍵、累加成本。這使大規模語料統計與反覆鍵位搜尋分離。

若加入三鍵動作成本，另保存三片段的聯合頻率，涵蓋字內及兩種跨字窗口；同一音節內的各片段必須來自同一讀音，不能將各段的邊際分佈獨立相乘。三鍵窗口至多跨兩個字，因此固定三鍵的本模型只需字頻和相鄰字對頻率，無需三字頻率。

## 4. 按鍵模型與指標

鍵盤幾何、指法與鍵位映射分開保存。初版可採用傳統錯列 QWERTY 的標準指法，但 B 等邊界鍵須明定；日後可替換爲個人指法或分體鍵盤。每鍵記錄座標、手、手指、行與單鍵負擔。物理距離只是代理指標，不能直接宣稱是肌肉負荷或輸入時間。

| 指標 | 計算口徑 | 用途 |
| --- | --- | --- |
| 單鍵負擔 | 依實際出現次數加權各物理鍵的單鍵成本 | 衡量伸展、非主行及較難按位置的使用量 |
| 同指異鍵連打 | 相鄰兩鍵不同，但使用同一手指的比例及移動距離 | 評估同指換位；分開字內與跨字統計 |
| 同鍵連打 | 相鄰兩鍵相同的比例 | 與同指異鍵分列，避免假定兩者成本相同 |
| 跨行與橫向伸展 | 同手組合的幾何特徵與發生次數 | 發現大幅移動或相鄰指的難按組合 |
| 三鍵動作 | 三鍵窗口內的同手換向、內滾／外滾等 | 補足二鍵模型看不到的動作；權重待校準 |
| 手指及左右手負荷 | 各指按鍵佔比、最大指負荷、左右手比例 | 避免高頻操作集中；不要求八指等量或強制左右各半 |
| 尾部成本 | 字頻加權的音節成本第 95 百分位、最差高頻字／詞 | 防止平均改善掩蓋常用難打組合 |

交替手、滾動等先作描述性指標；不要一律給交替手最高獎勵。速度、舒適度、錯誤率應分開觀察。[Engram 研究](https://doi.org/10.1080/10447318.2026.2665409) 提供依 n-gram 與實測偏好做多目標優化的參考，但其具體係數不能當作本人的已校準成本。

所有比例明定分母：按鍵負荷以按鍵總數計，二鍵特徵以有效相鄰鍵對數計，三鍵特徵以有效三鍵窗口數計。不能將「每字」與「每鍵對」直接混加。每千字成本亦須說明是否包含上屏與選字操作。

## 5. 字頻與相鄰字頻如何進入評分

對某鍵表 L，音節 s 的三鍵爲 aₛ、bₛ、cₛ。令 u(k) 爲單鍵成本，v(k,l) 爲有方向的相鄰鍵成本。以長串、連續三鍵輸入爲近似，每字成本爲：

```text
J(L) = Σₛ p(s) [u(aₛ)+u(bₛ)+u(cₛ)
                 + v(aₛ,bₛ)+v(bₛ,cₛ)]
       + Σₛ,ₜ p(s,t) v(cₛ,aₜ)
```

此處 p(s,t) 表示每輸入一字所產生的 s→t 邊界的期望次數；長串內總和接近 1，若按句斷開則小於 1。實作時最好直接以總次數除有效字數，避免把少量邊界重新正規化成每字都有邊界。

**字內有兩次銜接，字間還有一次。** 因此只按字頻評估三鍵組合，會漏掉長串輸入約三分之一的相鄰鍵對。只有字頻時可以先算字內分數，但不能標作完整連打評分。

詞頻可按詞的頻率展開成音節串，計算詞內跨字銜接；它仍缺少詞與詞之間的銜接。完整有序文本的相鄰字統計更完整，也不依賴古漢語斷詞標準。若只取詞頻表前若干項，還須報告截斷覆蓋率。

加入三鍵成本 w 時，從實際按鍵串統計所有窗口，包括 aₛbₛcₛ、bₛcₛaₜ、cₛaₜbₜ，不能只看單字自身的三鍵。手指負荷的非線性懲罰另算，避免混入局部成本而重複計分。

目前三鍵試驗使用兩種互斥特徵：三鍵同手、相鄰均換指的方向折返；中間爲異手、首末同指異鍵的隔鍵換位。前者附加 0.8，後者附加 0.8 加 0.3 倍首末物理距離，再乘全局三鍵權重 λ。三鍵統計保留全部三種窗口；各類比例以該類窗口數爲分母，總比例以三類窗口總量爲分母。內滾、外滾只列比例，尚未給獎勵。這些係數爲探索假設，不是已測得的時間。

若每字需按空格，字間路徑就變成 cₛ→Space→aₜ。需要選字或翻頁時，也將操作加入回放。先分別報告「純編碼連打」與「實際 Rime 操作」，不要用一套假定代替另一套。

u、v、w 初版只是可公開、可修改的相對成本；可按特徵線性組合，但重疊特徵要檢查重複懲罰。只有以實測按鍵時間校準並驗證後，才能用毫秒表示預測時間。

## 6. 如何比較與搜尋

先通過硬條件，再看各項原始指標與古今分榜。優先保留 Pareto 候選：若另一方案所有目標均不差且至少一項更好，則淘汰被支配者。不同目標互有勝負的方案應並列，不能用任意權重掩蓋取捨。

需要單一搜尋分數時，事先固定特徵尺度、成本係數與語料權重，以現用鍵表爲基準報告差額；基準爲零的指標報絕對值，不除以零。係數尚未校準時，至少測試數組係數，保留排名穩定者，不把分數下降百分比解釋爲打字提速百分比。

若使用者指定古今使用比例 α，可使用：

```text
Jmix(L) = α J古文(L) + (1−α) J現代文(L)
```

兩者須使用同一成本單位和每字分母；現代文內部的書面／口語權重另行明定。沒有指定比例時，用 α=0、0.25、0.5、0.75、1 作敏感度分析，而不選定其中一個爲真實使用比例。

首輪先保持共鍵組，對 K1／K2／K3 的配鍵作交換或移至閒置鍵，以多個固定隨機種子作爬山或模擬退火。這是組合搜尋的啓發式結果，不聲稱全局最優。第二輪才嘗試重組共鍵，每次重新驗證。

按作品、作者或來源切分訓練、驗證、測試集；同一作品不同版本不跨集合。選好方案與係數後才看保留測試集。對作品或文檔作配對 bootstrap，報告鍵表間的成本差及不確定範圍；不要逐字獨立抽樣來低估同一篇文本內的相關性。

最後以熟練程度相近的實打測試校準：記錄按鍵間隔、錯誤率、修正後速度及舒適度，交錯測試順序以減少疲勞影響。練習僅用於使測試條件可比，學習耗時不進入方案分數。

## 7. 最小可實作版本與報告格式

建議依次完成：

1. 匯入一組古文和一組現代有序文本，一次產生字頻及相鄰字對頻率，保存來源清單、轉字與邊界規則；若只能取得字頻，標記爲部分評價。
2. 對去重讀音等概率分配，預計算片段聯合頻率，生成現用鍵表的字內、跨字與三鍵窗口基線及覆蓋率。
3. 比較固定共鍵組的候選鍵表，輸出分項表及造成差異最大的高頻字、詞、字對。
4. 驗證跨語料、跨係數的穩定性，再選少數方案實打；其他多音字概率模型留作後續擴充。

建議的資料介面（名稱爲待實作規格）：

| 輸入／輸出 | 必要內容 |
| --- | --- |
| 語料 manifest | 來源、版本／雜湊、許可、文體、清洗規則、訓練／測試歸屬 |
| 字音頻率 | 語料、字符、全拼、次數、讀音分配依據／不確定標記 |
| 字對頻率 | 語料、前字、後字、次數、有效字數 N、有效字對數 B、邊界政策 |
| 音節相鄰頻率 | 語料、前音節、後音節、次數、邊界政策 |
| 鍵盤 profile | 幾何、指法、成本模型及係數、是否包括操作鍵 |
| 鍵表 JSON | 沿用現有 version/name/keys 格式 |
| 評價報告 | 鍵表及資料雜湊、合法性、覆蓋率、古今各項指標、與基線差額、最差高頻項、敏感度結果 |

完成這些資料前，可以比較結構性指標，但不發布「已按古今頻率優化」的結論。框架始終以實際按鍵負擔爲目的，不對鍵位的字母聯想或記憶規律加分。
