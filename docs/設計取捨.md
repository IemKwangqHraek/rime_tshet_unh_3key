# 小改版的設計取捨

現行方案保留原拼音，以少量修訂及共鍵完成三鍵編碼。完整規則與唯一現用鍵表見[全拼與三拼方案](全拼與三拼方案.md)。

## 要求與已驗證範圍

- 全拼只用 26 個小寫字母，音節內不用隔音符號。
- 每個音節包括聲調恰按三鍵；空片段也有對應鍵。
- 同一字面片段固定查同一鍵，不看其他片段臨時換鍵。
- 完整三鍵區分已驗證的不同地位及補充音節；同音字共碼是預期行爲。
- 三段按序拼合，允許明定的 `ii/yy/rr/jj` 縮合。爹全拼 `tiae`、三段 `t/va/∅` 是明定例外。

目前的來源聯集爲 3,808 地位，加怎共 3,809 條，使用 24／23／21 鍵。第二段有 52 種字母串，依搭配關係共用 23 鍵；23 是已驗證可行的數目，未宣稱最小值，也未按字頻優化手感。

## 輸入局部性與立即解析

輸入者想到 `taengq` 後，依次查 `t`、`ae`、`ngq`，得 `TCF`。即使 `ae` 與其他片段共鍵，查鍵仍只依當前片段完成。

立即解析則是另一項更強的限制：讀到 K1 要能確定第一段，讀到 K2 要能在尚未看見 K3 時確定第二段。本版不要求這件事。例如尸 `VII → hji` 與輸 `VIK → hyo` 的前兩鍵相同，第三鍵完成後才消歧。

端知章的共鍵來自共同基幹 `t`：東 `t/wu/ng`、中 `t/ru/ng`、終 `t/ju/ng`。這種分段本身允許先輸出 `t`，但不意味着整張 K2 表已能立即解析。顯式等類標記既保留音節區別，也讓這些聲母能共用第一鍵。

採用候選字詞與全拼提示，是後續輸入介面的回饋方向。現有推導腳本與碼表提供所需數據，尚未實作候選視窗。不爲立即解析另增 `kr/khr/hr/qr`，也不恢復見組按三等性分寫。

## 相對原拼音的主要修訂

| 項目 | 現行選擇 |
| --- | --- |
| 東一、侯 | `ou → wu`；尤仍爲 `u` |
| 豪 | `oa+w`；冬的 `ow` 仍是整體韻核 |
| 蒸 C | `v` 韻核；蒸 B 用 `i` |
| 莊組庚三 | 保留三 B，如 `sriaeng`，不歸二等 |
| 曉三 A 合口 | 用 `x` 消歧，去掉原來的隔音符號 |
| 普通脂 | 三拼另設 `i` 尾，與韻核縮合；地不套用 |
| 特殊字 | 箉 `greq`、打 `taengq`、冷 `laengq`、地 `dih`、爹 `tiae`、怎 `tsvmq`、𩦠 `biangq` |

這裏的拼式 A／B／C 是明定的書寫分類；知莊強制 B、章日以強制 A，不等於宣稱它們都有與鈍音重紐相同的音位對立。字母與韻核記號也不一律逐字母對應 IPA，相關證據與限度見[音系與豪韻](音系與豪韻.md)。

## 新資料引起的鍵位修正

舊固定樣本沒有𩦠的並三 A 陽上地位。加入該讀音 `biangq` 後，若第二段 `ia/rae` 仍共 A，便與 `braengq` 同爲 `BAF`。本版只將 `ia` 移到 J，使𩦠爲 `BJF`，`braengq` 仍爲 `BAF`；原樣本有 4 個三鍵碼受影響，全拼不變。

官方內建資料與固定版《廣韻》也不是完全相同的集合。本版保留聯集，不藉刪除異常地位來避免碰撞。版本、差異清單與重現方法見[資料來源與重現](資料來源與重現.md)。
