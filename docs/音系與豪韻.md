# 拼式一致性與豪韻審核

## 現行拼式

主設定爲東一、侯 `wu`，豪 `oaw`，蒸 C `v`，莊組庚三仍爲三等 B 拼式。普通脂韻保留已約定的 i 尾編碼。52 種第二段仍可分入 23 鍵，三鍵數爲 24／23／21。

韻核改寫對鍵位的影響：`wu` 接替 `ou` 的 G 鍵；豪韻的 `oa` 仍與普通 `a` 共 B 鍵。因此「直接替換」對輸出拼式成立；在片段集合中 `a→oa` 不是整個 a 類改名，而是從仍用於其他韻的 a 中分出一串，但不必多佔按鍵。

原數據中 6 個莊組庚三地位恢復顯式三 B 拼式，如生 `sraeng→sriaeng`、省 `sraengq→sriaengq`、柵 `tshraek→tshriaek`。實際音韻地位不改；改的是原程式把它們按二等拼寫的例外。

「怎」tsvmq 已寫入補充碼表及全拼查碼表，主版爲 `ts / v / mq → FNV`，與已核對的 3,808 個來源地位都不衝突。可以執行：

```sh
npm run derive -- --char 怎 東 豪 生
```

## 尚需說清的音系與拼寫關係

沒有發現另一個必須大改全拼才能保住音節區別的硬性矛盾，但以下不能混作同一層的音系斷言：

| 項目 | 問題與建議 |
| --- | --- |
| 「知莊三等強制 B」 | 這是本方案的**拼式 B 類**，不等於證明所有知莊三等都屬鈍音的音韻 B 類。來源音韻標註與拼寫分類分開保存。尤其知、莊的音值分析不必因共鍵而完全相同。 |
| 「支侵宵 B 用 C」 | 沿用原程式，排除知莊組；否則會錯改 `trie / tsrim` 等。不能在說明中把這條簡寫爲對所有聲母無例外的規則。 |
| 「a 是後元音」 | 這個舊說明過強，已修正。參考分析把寒談的 [a] 與歌唐的 [ɑ] 分開，並容許二者互補。拼音可以都用 a，但豪韻不像歌唐 [ɑ]，不等於豪韻一定不能是央低 [a]。 |
| `u`、`o`、`w` 等字母 | 字母不是逐個對應 IPA。`wu` 爲東一／侯韻核的複字母記號，不聲稱一定有一個獨立 /w/ 介音；`ow` 已作冬韻的整體韻核記號。本方案據此保留豪韻 `oa+w`，不再採用豪 `o+w` 的候選。 |
| 書船與曉母 | `hj/hy`、`ghj/ghy` 是聲母串及拼式變體；不必將其按字面解釋爲曉／匣加真實 j。曉三 A 合口的 x 是消歧用異形，不表示另有一個聲母音位。 |
| 脂、爹、打冷 | 脂的 i 尾是編碼分析，可由 ii→i 保持全拼；爹是明定例外。打冷取消 r 也沿用已選讀音。不能用這些特例反推全部韻核的擬音。 |

這些大多需要補足術語說明，而不是再改一批拼式。參考分析本身也區別音系結構和較直觀的轉寫，並未要求每個拉丁字母都有唯一音值。[unt：切韻擬音 L](https://phesoca.com/aws/337/)

## 豪韻：區分三個強度不同的命題

1. **豪韻不宜直接按歌唐的後低元音理解：有值得採納的理由。** 參考文從效攝通押、日語吳音的唇音對應及反切分群，提出豪韻可能更偏央、中元音。
2. **豪韻只能是中元音，不能是普通低元音：尚未確證。** 通押是接近性的證據，不直接給出確切音值；借音要區分時代、方言及接受語適配；聲母部位引起的分群也不唯一決定元音高度。
3. **所以必須寫成 ow：不成立。** 音值假說、音位分析、拉丁拼寫是三個決定。即使音值有別，也可將之視爲 a 在 w 尾前的實現，不一定新增獨立音位或字母串。

原文並非斷定所有豪韻讀 [ow]：現版 L 用 **əw**，早先用 **ʌw**，通俗轉寫仍保留 **aw**。因此「有獨特性」的論據比「確定是某個圓唇後中元音」強。[參考原文及版本歷史](https://phesoca.com/aws/337/)

### 對反切論據的獨立核查

使用本項目固定版《廣韻》，按小韻首字統計豪／皓／號。下字只在同一韻內的已知讀音可唯一判爲唇音或非唇音時歸類；不以每個條目重複計數。

| 本字聲母群 | 下字唇音 | 下字非唇音 | 未定 |
| --- | ---: | ---: | ---: |
| 唇音 | 7 | 2 | 1 |
| 非唇音 | 1 | 43 | 0 |

54 個小韻中有 53 個可按此機械口徑判定，其中三個跨群：蒿「呼毛」、抱「薄浩」、蓩「武道」。報「博耗（秏）」有下字異文，本文字頭索引只直接收得秏，故保守列未定，未偷偷當成同群。

可以說多數同群用下字，但不能說完全不互切；唇音的可判定小韻中仍有 2/9 跨群。對照唐韻，本字唇音的 14 個小韻有 13 個使用非唇音下字，顯示豪韻的分群傾向確實值得解釋。不過不同韻的反切下字庫、選字慣例和校訂情形有差異，這不是控制完備的獨立樣本試驗，更不等於測出了 /ə/。

原始逐項結果：[豪韻](../data/fanqie/豪-fanqie.tsv)、[唐韻](../data/fanqie/唐-fanqie.tsv)、[摘要](../data/fanqie/fanqie-summary.json)。這是對《廣韻》本版的核查，不冒充對所有《切韻》殘卷的考證。

### 後世證據的限度

參考作者自己的《中原音韻》分析容許低元音韻基 aw 和帶圓唇成分的 waw，唇音豪韻來源多歸後者。這提醒我們：唇音特別圓化不必唯一歸因於中古中元音；且元代材料只能作中古構擬的間接限制。[《中原音韻》音系簡述，萧豪韻一節](https://phesoca.com/aws/311/)

閩南豪韻也有 au、o 等多層讀音，研究對層次來源另有分析。不能把某一現代方言的 o 直接當成切韻時代的 o，也不能把現存 au 當作從未發生變化的確證。[關於閩南話中效攝一等字的文白異讀](https://www.cuhk.edu.hk/ics/clrc/scl_11/higuchi.pdf)

## 對拼寫的建議

目前保留已指定的 **oaw**，將 **oa 定義爲豪韻專用的單一韻核記號**，不按字面讀成兩個元音，也不宣稱該拼式本身證明某個確定音值。

後續已確定：冬韻既以 `ow` 爲整體韻核，就不再選豪 `o+w`，以保持方案內韻核記號與分段的一致性。即使參考分析採 əw，也不強制全拼逐字母照寫；現行豪韻固定 `oa+w`。

豪 `ow` 不列入現行候選。現行拼式與新版推導器鍵表見[全拼與三拼方案](全拼與三拼方案.md)。

反切統計重現：先執行 `npm run fetch:sources` 下載固定版本，再以 `npm run audit:fanqie` 核對已提交的結果。下載檔存於不提交的 `.cache/upstream/`，腳本核對 SHA-256 後才分析。另可用 `python3 scripts/analyze_hao_fanqie.py --source /path/to/廣韻.csv --check` 指定已下載檔案。來源見[資料來源與重現](資料來源與重現.md)。
