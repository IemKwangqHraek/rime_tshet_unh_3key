```sh
npm ci --ignore-scripts
npm test
```

`npm test` 比較完整已提交快照，不覆寫 `data/`。它同時驗證片段查鍵一致、全拼與三鍵無碰撞、特殊音節與多音字、文檔鍵表和例字。需要調整方案時：

```sh
npm run build:data
git diff -- data/
npm test
```

應先審核差異，再接受新快照；不要只爲讓測試通過而重生成。`build:data` 不修改文檔中的手寫鍵表，文檔核查會攔截表格與機讀碼表不一致的情況。

### 可選：下載上游並重現反切核查

```sh
npm run fetch:sources
npm run audit:fanqie
```

`fetch:sources` 下載上述兩個固定版本檔案，驗證 SHA-256 後存入 `.cache/upstream/`。已存在的快取也會校驗；校驗失敗即停止。下載的 JavaScript 不執行，快取不提交。

反切核查只需 Python 3 標準庫；`audit:fanqie` 校驗 CSV、來源集合和已提交統計，不改寫結果。要明確重生成反切統計，執行 `python3 scripts/analyze_hao_fanqie.py`，再審核 `data/fanqie/` 差異。其他檔案路徑可用 `--source /path/to/廣韻.csv` 指定。

上游下載只供來源審核及反切研究；日常查字、推導和常規測試不依賴 `.cache/` 或本地歷史目錄。升級依賴或原始資料時，應重新核對來源清單、聯集、全部拼式與鍵位，不能只改版本號。
